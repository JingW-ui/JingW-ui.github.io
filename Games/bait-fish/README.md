# 饵食大逃亡 (Bait Escape)

原作品: [Amoshe2026/bait-fish](https://github.com/Amoshe2026/bait-fish) — 逆向钓鱼像素街机：扮演小鱼偷吃钩上的饵食成长、躲避鱼钩的反击，20 波跃龙门通关，支持单人模式与双人键盘对战（P1 WASD+Shift 冲刺 / P2 方向键+Enter 抄网）。

本目录为上游 `index.html` 的原样收录（纯 HTML5 Canvas + Web Audio，零外部依赖），部署时仅补充了浏览器标签页标题。版权归原作者 Amoshe2026 所有；原仓库未设开源许可，本站收录供学习交流，如有异议即删除。
