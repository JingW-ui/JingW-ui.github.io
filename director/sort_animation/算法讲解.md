# 1️⃣ 冒泡排序（Bubble Sort）
## 思想
相邻元素两两比较，把较大的元素“冒”到右侧。

## Python 实现
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr
```

## 复杂度
- 时间复杂度：**O(n²)**
- 空间复杂度：**O(1)**
- ✅ **稳定排序**

# 2️⃣ 选择排序（Selection Sort）
## 思想
每一轮选出最小元素，放到已排序区间末尾。

## Python 实现
```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr
```

## 复杂度
- 时间复杂度：**O(n²)**
- 空间复杂度：**O(1)**
- ❌ **不稳定排序**

# 3️⃣ 插入排序（Insertion Sort）
## 思想
像整理扑克牌，将每个元素插入到已排序部分的正确位置。

## Python 实现
```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr
```

## 复杂度
- 时间复杂度：**O(n²)**
- 空间复杂度：**O(1)**
- ✅ **稳定排序**

# 4️⃣ 希尔排序（Shell Sort）
## 思想
插入排序的改进版，通过 **分组 + 增量** 减少移动次数。

## Python 实现
```python
def shell_sort(arr):
    n = len(arr)
    gap = n // 2
    while gap > 0:
        for i in range(gap, n):
            temp = arr[i]
            j = i
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap
            arr[j] = temp
        gap //= 2
    return arr
```

## 复杂度
- 时间复杂度：**O(n^1.3)**（取决于间隔序列）
- 空间复杂度：**O(1)**
- ❌ **不稳定排序**

# 5️⃣ 归并排序（Merge Sort）
## 思想
**分治法**：  
1. 拆分成两半  
2. 分别排序  
3. 合并两个有序数组

## Python 实现
```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

## 复杂度
- 时间复杂度：**O(n log n)**
- 空间复杂度：**O(n)**
- ✅ **稳定排序**

# 6️⃣ 快速排序（Quick Sort）
## 思想
选一个基准值（pivot），将数组划分为：
- 小于 pivot
- 等于 pivot
- 大于 pivot  
然后递归处理左右部分。

## Python 实现（常见写法）
```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr

    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]

    return quick_sort(left) + middle + quick_sort(right)
```

## 复杂度
- 平均时间复杂度：**O(n log n)**
- 最坏时间复杂度：**O(n²)**
- 空间复杂度：**O(log n)**（递归栈）
- ❌ **不稳定排序**
