# 《口技》十景 - 戴敦邦国画风互动体验

一个融合传统国画艺术与现代Web技术的沉浸式互动体验，将清代文学家林嗣环的经典散文《口技》以全新的视觉和听觉形式呈现。

## 项目特色

### 🎨 视觉艺术
- **戴敦邦国画风格**: 10张工笔重彩风格插图，完美还原明代生活场景
- **16:9横屏设计**: 1920×1080高清分辨率，适配现代屏幕
- **米纸质感**: 传统国画材质感，温暖色调
- **留白美学**: 体现中国传统绘画的留白艺术

### 🔊 听觉体验
- **口技音效**: 10段15秒循环音频，模拟各种生活声音
- **环境音效**: 厅堂、卧室、火灾等不同场景的氛围音效
- **人声模拟**: 婴儿啼哭、大人呵斥、人群惊呼等真实声音
- **无缝循环**: 音频循环播放，营造持续氛围

### 🎮 交互功能
- **卷轴式浏览**: 纵向滚动体验，如观画卷
- **自动播放**: 8秒自动切换场景，完整体验
- **手动控制**: 自由滚动浏览，点击导航跳转
- **音量控制**: 实时调节音量，支持静音
- **键盘操作**: 空格键播放/暂停，方向键切换场景

## 技术实现

### 前端技术栈
- **HTML5**: 语义化结构，支持现代浏览器
- **CSS3**: Flexbox布局，CSS动画，响应式设计
- **JavaScript ES6+**: 原生JS，无外部依赖
- **Web Audio API**: 音频播放和控制

### 性能优化
- **图片懒加载**: 只加载当前和下一个场景的图片
- **音频预加载**: 预加载当前场景音频，确保流畅播放
- **内存管理**: 离开场景时释放音频资源
- **渐进式增强**: 不支持某些功能的浏览器也能正常浏览

### 兼容性
- Chrome 80+
- Safari 13+
- Firefox 75+
- 移动端浏览器

## 使用说明

### 启动方式
1. 下载所有文件到本地目录
2. 使用Python启动本地服务器：
   ```bash
   python -m http.server 8000
   ```
3. 在浏览器中访问 `http://localhost:8000`

### 操作指南
- **滚动**: 鼠标滚轮或触摸滑动切换场景
- **自动播放**: 点击"自动播放"按钮开始自动体验
- **音量控制**: 使用音量滑块调节音量
- **快速跳转**: 点击右侧导航点直接跳转到指定场景
- **键盘操作**: 
  - 空格键：播放/暂停自动播放
  - 方向键：上下切换场景
  - M键：静音/取消静音

## 创作背景

本项目旨在通过现代Web技术，将中国传统文化经典以全新的形式呈现给当代观众。戴敦邦先生的国画艺术风格为整个项目提供了深厚的文化底蕴，而互动技术的应用则让古典文学焕发出新的生命力。

《口技》作为清代林嗣环的代表作，生动描绘了一位口技艺人的精彩表演，通过声音的层层递进，营造出从宁静到混乱再到戛然而止的戏剧效果。本项目正是要通过视觉和听觉的结合，让用户身临其境地体验这一文学经典。
