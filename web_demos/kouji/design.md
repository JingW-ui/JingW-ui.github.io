# 《口技》网页视觉设计

## 设计理念

### 传统与现代的融合
- **国画美学**: 采用戴敦邦工笔重彩风格，体现中国传统艺术精髓
- **现代交互**: 运用现代Web技术创造流畅的用户体验
- **文化内核**: 通过视觉设计传达《口技》文学作品的深刻内涵

### 色彩系统
- **主色调**: 暖褐色系（#8B4510, #A0522D, #CD853F）
- **辅助色**: 米黄色（#F5E6D3, #F7F3E9）
- **强调色**: 深红色（#8B0000）用于重要元素
- **背景色**: 淡雅米色，模拟宣纸质感

### 字体设计
- **标题字体**: 使用优雅的衬线字体，如"Ma Shan Zheng"或"Noto Serif SC"
- **正文字体**: "Noto Sans SC"确保可读性
- **装饰字体**: 书法风格用于特殊标题

## 视觉效果

### 卷轴动效
```css
/* 水墨晕染效果 */
.scene-transition {
  mask-image: radial-gradient(circle, black 60%, transparent 100%);
  animation: inkSpread 1.5s ease-in-out;
}

/* 文字浮现效果 */
.text-reveal {
  opacity: 0;
  transform: translateY(30px);
  animation: fadeInUp 1s ease-out 0.5s forwards;
}
```

### 粒子系统
- **水墨粒子**: 场景切换时的水墨扩散效果
- **光点效果**: 烛光、火光的动态表现
- **烟雾效果**: 火灾场景的烟雾缭绕

### 光影效果
- **体积光**: 烛光和火光的体积光效果
- **投影**: 人物和物体的真实投影
- **环境光**: 整体场景的柔和光照

## 布局设计

### 响应式网格
```css
/* 移动端优先 */
.scene-container {
  width: 100vw;
  height: 100vh;
  display: flex;
  flex-direction: column;
}

/* PC端增强 */
@media (min-width: 768px) {
  .scene-container {
    max-width: 1920px;
    margin: 0 auto;
  }
}
```

### 内容层次
1. **背景层**: 戴敦邦国画插图
2. **内容层**: 原文和今译字幕
3. **交互层**: 播放控制、音量调节
4. **特效层**: 粒子效果、光影动画

### 导航设计
- **进度指示器**: 底部横向进度条，显示10个场景位置
- **场景预览**: 鼠标悬停显示场景缩略图
- **快速跳转**: 点击进度条直接跳转到指定场景

## 动画效果

### 场景切换
- **淡入淡出**: 1.5秒的平滑过渡
- **水墨晕染**: 模拟国画水墨扩散效果
- **音画同步**: 音频与视觉效果的完美配合

### 文字动画
- **逐字显现**: 古文逐字出现的效果
- **颜色渐变**: 文字颜色的温暖渐变
- **位置移动**: 文字从下方滑入的动画

### 交互反馈
- **悬停效果**: 按钮和控件的悬停状态变化
- **点击反馈**: 点击时的视觉和听觉反馈
- **加载动画**: 资源加载时的优雅等待动画
