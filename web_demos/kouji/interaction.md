# 《口技》互动网页设计

## 核心交互理念

### 沉浸式卷轴体验
- **纵向全屏滚动**: 用户通过滚轮或触摸滑动来体验整个故事
- **场景切换**: 每个场景占据一个屏幕高度，滚动时平滑过渡
- **音画同步**: 进入每个场景时自动播放对应的口技音频

### 视觉设计特色
- **戴敦邦国画风格**: 工笔重彩，米纸质感，暖色调
- **卷轴动效**: 场景切换时的水墨晕染效果
- **字幕浮现**: 原文和今译以优雅的方式出现和消失
- **响应式设计**: PC和移动端自适应，支持触摸操作

### 音频体验
- **自动播放**: 场景进入视口时自动播放对应音频
- **循环播放**: 15秒音频无缝循环，营造持续氛围
- **音量控制**: 用户可调节音量或静音
- **预加载**: 音频预加载策略确保流畅体验

## 交互功能

### 1. 自动播放模式
- 页面加载后自动按顺序播放所有场景
- 每个场景停留约8-10秒
- 平滑过渡到下一个场景

### 2. 手动探索模式
- 用户自由滚动浏览
- 点击场景可暂停/播放音频
- 双击可快速跳转到下一个场景

### 3. 场景导航
- 底部进度条显示当前位置
- 点击进度条可快速跳转到指定场景
- 场景缩略图预览

### 4. 音效控制
- 音量滑块控制
- 静音按钮
- 音效开关（可关闭口技音效，仅保留背景音乐）

## 技术实现要点

### 性能优化
- 图片懒加载：只加载当前和下一个场景的图片
- 音频预加载：预加载当前场景的音频
- 内存管理：离开场景时释放音频资源

### 兼容性
- 支持现代浏览器（Chrome 80+, Safari 13+, Firefox 75+）
- 移动端触摸优化
- 渐进式增强：不支持某些功能的浏览器也能正常浏览

### 用户体验
- 加载动画：页面初始加载时的优雅过渡
- 错误处理：音频加载失败时的优雅降级
- 无障碍支持：键盘导航和屏幕阅读器支持
