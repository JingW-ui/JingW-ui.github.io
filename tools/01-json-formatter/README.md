# JSON 格式化 / 校验工具

> 工具编号：01 | 分类：文本处理类

## 功能简介

一款纯前端 JSON 处理工具，无需后端，所有操作本地完成，保障数据隐私安全。

## 核心功能

- **JSON 格式化**：支持 2空格 / 4空格 / Tab 缩进
- **JSON 压缩**：去除多余空白，生成最小化 JSON
- **语法校验**：实时校验并精确提示错误位置
- **语法高亮**：键名、字符串、数字、布尔值、null 区分着色
- **JSON → CSV**：将 JSON 数组转为 CSV 表格格式
- **JSON → XML**：将 JSON 对象/数组转为 XML 格式
- **实时状态**：字符数、行数、文件大小实时显示
- **复制结果**：一键复制当前视图内容

## 使用方式

1. 打开 `index.html`（直接双击或使用本地服务器）
2. 在左侧输入区粘贴或输入 JSON 内容
3. 点击工具栏按钮执行对应操作
4. 快捷键：`Ctrl + Enter` 快速格式化

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript
- 无外部依赖，单文件运行
