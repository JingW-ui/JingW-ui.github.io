# 思维导图 Mindmap

将 Markdown 大纲实时渲染为交互式思维导图,支持折叠/缩放、节点编辑、导出 PNG/SVG。

来源与许可:
- 项目:[kongkongyo/Ai-Markmap](https://github.com/kongkongyo/Ai-Markmap)(MIT)
- 依赖:d3、markmap-lib、markmap-view(经 CDN 加载,本地不保存)

## 功能

- 📝 左侧 Markdown 编辑,右侧实时渲染思维导图
- 🔀 折叠/展开、缩放拖拽、节点增删改
- 🖼️ 导出 PNG / SVG
- 🤖 可选接入自定义 AI API 生成导图(需自备 Key,不用可忽略)

## 使用

打开页面,在左侧输入 Markdown(标题为根节点,列表为分支),右侧自动生成;点击节点可编辑。
