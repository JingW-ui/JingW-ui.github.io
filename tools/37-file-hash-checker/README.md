# 文件哈希校验工具

> 工具编号：37 | 分类：其他实用工具

## 核心功能

- **多算法计算**：MD5、SHA-1、SHA-256、SHA-512 同时计算
- **拖拽上传**：支持拖拽文件，无需服务器，纯本地计算
- **哈希校验**：粘贴已知哈希值，自动比对验证文件完整性
- **文件信息**：显示文件名、大小、类型、修改时间
- **一键复制**：每种算法结果独立复制按钮

## 技术说明

- MD5：纯 JavaScript 实现
- SHA-1/256/512：使用 Web Crypto API
