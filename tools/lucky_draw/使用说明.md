# 抽签器数据管理功能使用说明

## 🎯 如何打开数据管理器（隐蔽触发方式）

以下任意一种方式都可以打开数据管理界面：

### 1️⃣ 快捷键方式（推荐）
- 同时按下 `Ctrl + Alt + D`

### 2️⃣ 鼠标操作方式
- **连续点击标题** "LUCKY DRAW" **3次**
- 在剩余人数显示区域（REMAINING: XX）**右键点击**
- 按住重置按钮（RESET）**3秒钟**
- 在历史记录区域按住 `Shift` 键并**双击**

---

## 📋 数据管理器功能

### 1. TEXT - 文本导入
- 每行输入一个名字
- 点击 IMPORT 按钮导入

### 2. EXCEL - Excel文件导入
- 支持拖拽上传 `.xlsx`, `.xls`, `.csv` 文件
- 或点击区域选择文件
- 自动读取第一个工作表的所有文本内容

### 3. JSON - JSON格式导入
- 输入JSON数组格式，例如：`["张三", "李四", "王五"]`
- 点击 IMPORT 按钮导入

### 4. MANUAL - 手动管理
- 逐个添加或删除学生
- 输入名字后按回车或点击 ADD 按钮
- 点击 × 按钮删除某个学生
- 实时显示学生总数

### 5. EXPORT - 导出数据
- **EXPORT TXT**: 导出为文本文件（每行一个名字）
- **EXPORT JSON**: 导出为JSON格式
- **EXPORT EXCEL**: 导出为Excel文件

---

## 💡 使用提示

1. **所有修改立即生效**：导入或修改数据后，抽签器会立即使用新的名单
2. **自动重置**：导入新数据后，已抽取的历史记录会被清空
3. **重复检测**：手动添加时会自动检测重名
4. **友好提示**：所有操作都有右上角的通知提示，不会弹出烦人的对话框

---

## 🔒 为什么设计得这么隐蔽？

这个功能面向教师用户，避免学生在课堂上误操作修改名单。只有知道秘密操作的老师才能访问数据管理功能。
