# Markdown 编辑器

> 工具编号：04 | 分类：文本处理类

## 核心功能

- **实时预览**：编辑与预览双栏同步显示
- **工具栏快捷操作**：粗体、斜体、标题、列表、代码块、表格等
- **键盘快捷键**：Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+S 本地保存
- **导出功能**：导出为 HTML 文件或 .md 文件
- **本地存储**：自动保存到 localStorage，刷新不丢失
- **三种视图**：双栏预览 / 纯编辑 / 纯预览
