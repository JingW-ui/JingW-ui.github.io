我想借用LLM api创建一个辅助脚本编写的纯前端网页工具
该工具支持草稿一键生成可编辑的视频脚本 支持多种格式导出
可配置api key 这个设置的隐蔽一点 
整体风格是黑灰色字体 白色背景 github绿色按钮作为点缀色 按钮中不要有icon 布局紧凑 适配手机端 
不要所有的按钮都是绿色的 主要功能按钮是绿色的 其他次要功能按钮可以是灰色的
脚本显示为专业的表格 具体到秒的时间段 有专业的分镜设计 方便用户编辑和调整
api 接口
curl --request POST \
  --url https://api.siliconflow.cn/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "Pro/zai-org/GLM-4.7",

  }'
