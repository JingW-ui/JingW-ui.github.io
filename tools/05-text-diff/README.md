# 文本对比 / 差异对比工具

> 工具编号：05 | 分类：文本处理类

## 核心功能

- **行级对比**：显示每行新增/删除/相同状态，带行号
- **字符级对比**：精确到字符的差异高亮
- **并排对比**：左右两栏同步对比视图
- **上下文控制**：显示差异周围 N 行上下文
- **导出 HTML**：一键导出带样式的对比结果

## 技术说明

使用 LCS（最长公共子序列）算法实现差异检测。
