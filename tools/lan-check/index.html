    使用说明与原理
    • 用法：电脑端打开本页生成二维码 → 手机相机扫码 → 手机页面自动完成连接测试并给出「连通 / 不连通」结果。
    • 原理：电脑与手机各自打开本页后，直接在局域网内互相握手——能连上即连通，连不上即被隔离或不在同一网段。
    • 隐私：IP 与设备信息仅在两台设备间直接交换，不经任何服务器存储；房间码随机生成、用完即弃。
    • 提示：若显示不连通，请检查是否连接同一 Wi-Fi、是否被访客网络 / AP 隔离 / 公司防火墙限制。
