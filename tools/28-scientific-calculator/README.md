# 科学计算器

> 工具编号：28 | 分类：计算/进制类

## 核心功能

- **基础模式**：四则运算、百分比、平方根、平方
- **科学模式**：三角函数(sin/cos/tan)、反三角、对数(log/ln)、指数、π/e 常数
- **程序员模式**：进制转换(BIN/OCT/DEC/HEX)、位运算(AND/OR/XOR/NOT)
- **历史记录**：记录最近20条计算历史，点击可复用
- **键盘支持**：数字键、运算符、Enter、Backspace、Esc
- **内存操作**：MC/MR/M+/M-/MS
