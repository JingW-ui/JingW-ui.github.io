# 简易待办清单工具

> 工具编号：35 | 分类：其他实用工具

## 核心功能

- **任务管理**：添加/删除/编辑/完成待办事项
- **分类管理**：工作/学习/生活/购物/其他
- **优先级**：高/中/低三档，颜色区分
- **截止日期**：支持设置到期日，高亮逾期任务
- **过滤视图**：全部/进行中/已完成/今日到期
- **进度条**：实时显示完成比例
- **本地存储**：数据保存到 localStorage，刷新不丢失
