# Base64 编解码工具

> 工具编号：03 | 分类：文本处理类

## 核心功能

- **文本编解码**：文本 ↔ Base64 互转，支持中文和 Emoji
- **图片转 Base64**：支持拖拽上传，显示图片信息，一键复制 `<img>` 标签或 CSS `url()`
- **批量处理**：多行批量编码/解码，支持导出结果
- **Base64 预览**：粘贴 Base64 字符串预览图片，支持下载
