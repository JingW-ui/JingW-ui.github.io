# 正则可视化 Regulex+

把 JavaScript 正则表达式渲染为铁路图(Railroad Diagram),直观理解匹配逻辑;支持中英界面、深/浅主题、导出 PNG/SVG。

来源与许可:
- 项目:[PipeDream941/regulex-plus](https://github.com/PipeDream941/regulex-plus)(MIT)
- 单文件内嵌,无构建

## 功能

- 🚂 正则 → 铁路图可视化(分支/量词/捕获组一目了然)
- 🌐 中英文界面切换、深浅主题
- 🖼️ 导出 PNG / SVG / Mermaid
- ✍️ 实时输入实时渲染

## 使用

输入正则(如 `^[a-z]+(\d+)?$`),下方实时生成铁路图;点击节点可查看对应片段解释。
