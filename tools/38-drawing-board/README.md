# 简易画板工具

> 工具编号：38 | 分类：其他实用工具

## 核心功能

- **绘图工具**：画笔、橡皮擦、直线、矩形、圆形、填充、文字
- **颜色选择**：原生颜色选择器 + 10个预设颜色
- **粗细/透明度**：滑块控制笔刷大小和透明度
- **撤销/重做**：最多50步历史记录
- **保存/导出**：保存为 PNG，复制到剪贴板
- **导入图片**：可加载图片作为底图
- **多画布尺寸**：800×600 / 1280×720 / 1920×1080 等
- **触屏支持**：移动端触摸绘图
