# 颜色取色 / 色值转换工具

> 工具编号：22 | 分类：图片/媒体类

## 核心功能

- **多格式色值转换**：HEX ↔ RGB ↔ HSL ↔ CMYK ↔ HSV 互转
- **RGB 滑块调色**：直观拖动 R/G/B/Alpha 滑块
- **EyeDropper 取色**：支持 Chrome 95+ 屏幕取色
- **配色方案生成**：类比色/互补色/三色组/分裂互补/四色组/明暗变化
- **30 个预设颜色**：常用颜色快速选取
- **一键复制**：复制任意格式色值
