📚 Skills 技能库

find-skills
帮助用户发现和安装 agent skills，当用户询问"如何做到X"、"查找X的技能"或表达扩展能力需求时使用。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --find-skills
skill-creator
指导创建有效的 Agent Skills，Skills 是教授 agent 如何执行特定任务的 markdown 文件。如果想创建自己的技能，应首先使用此技能。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --skill-creator
nature-academic-search
多源文献搜索、引用验证、MeSH搜索策略、引用文件管理(.nbib/.ris/.bib转换)和参考文献管理，通过MCP工具(PubMed、CrossRef、arXiv)实现。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --nature-academic-search
nature-citation
为手稿文本添加严格的Nature/CNS引用，通过分段搜索Nature系列、Science家族和Cell Press期刊，按时间范围过滤，导出引用管理器格式文件。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --nature-citation
nature-data
准备、审核或修订Nature就绪的数据可用性声明、数据存储库计划、数据集引用和FAIR元数据清单，支持中英文对照。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --nature-data
nature-figure
提交级别的Nature/高影响力期刊图表工作流，支持Python(matplotlib/seaborn)或R(ggplot2/patchwork)，生成期刊就绪的SVG/PDF/TIFF输出。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --nature-figure
nature-paper2ppt
从科学论文构建完整的Nature风格中文PPTX演示文稿，自动识别论文类型、选择关键图表、编写中文幻灯片内容和演讲备注。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --nature-paper2ppt
nature-polishing
使用写作策略原则和学术短语库，将学术散文润色、重构或翻译为Nature风格的英语，适用于摘要、引言、结果、讨论等章节。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --nature-polishing
nature-reader
构建全文中英文对照、图表感知、源锚定的Markdown阅读器，支持PDF、DOI、arXiv等来源，保留图表位置和精确源锚点。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --nature-reader
nature-response
起草、审核或修订Nature系列手稿修回的逐点审稿人回复信，处理大修/小修请求，提供可追溯的回复包。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --nature-response
nature-writing
从作者提供的论点、结果、图表、笔记或中文草稿中起草、重构或规划Nature风格的手稿章节，而非仅润色已完成的文章。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --nature-writing
python-auto-type
自动将Python代码输入到任意目标窗口，模拟真实打字行为，包含错误纠正和可自定义延迟，需要pyautogui依赖。
安装命令：
npx skills add https://github.com/JingW-ui/JingW-ui.github.io/tree/main/skills --python-auto-type
