# AI 腔黑名单

改写措辞（方法论第 4 步）时主动规避这些词。灵感来自 Resume-Matcher 的 AI-phrase removal 轮：用固定清单替代"凭语感"，避免 JD 关键词织入时带进明显的 AI 生成腔。

## 使用规则

1. 改写项目描述时，产出句子里出现下列词汇 → 换成右侧的替代表达或直接重写。
2. 黑名单只管"腔调"，不改变内容事实——不要为了避开词汇而删掉量化成果。
3. JD 原文里出现这些词时，织入的是 JD 的**能力点**而不是这些空话本身。

## 空话动词类

| 黑名单 | 替代表达 |
|---|---|
| 负责了 / 负责xx工作 | 独立完成 / 主导 / 搭建（写清具体对象） |
| 深度参与 | 主导 / 实现（写清做了什么） |
| 赋能 | 用于 / 支撑 / 提效 |
| 助力 | 使 / 提升 / 减少 |
| 致力于 | 专注于（或直接删掉，写做了什么） |
| 着力打造 | 搭建 / 开发 |
| 全方位 / 多维度 | 删掉或换成具体维度（如"覆盖构建、测试、部署"） |
| 深度融合 | 结合 / 集成 |
| 完美解决 | 解决（量化效果） |
| 极大提升 / 显著提升 | 提升后接数字（如"构建耗时降低 40%"） |

## 模板句式类

| 黑名单 | 问题 |
|---|---|
| 基于 XX 技术实现了 XX，提升了 XX | 没有数字的"提升"是空话；有数字就直接写数字 |
| 沉淀了 XX 方法论 / 最佳实践 | 应届生简历里多为拔高；写成具体产出（文档、工具、规范） |
| 形成闭环 | 写清流程首尾（如"从需求评审到灰度上线"） |
| 打通 XX 链路 | 写清具体接了哪两个系统 |
| 一站式 XX | 写清覆盖了哪些环节 |
| 降本增效 | 分开写：降了多少本、提了多少效 |
| 快速上手 / 学习能力强 | 这是自我评价不是事实，用 GPA/获奖/跨方向项目佐证 |

## 中文技术简历特有

| 黑名单 | 说明 |
|---|---|
| 熟练掌握 / 精通 | 招聘官普遍反感；用"使用 X 完成 Y"的事实句 |
| 了解 / 熟悉（技能清单里） | 专业技能板块已改用 `.skill-line` 流式文本，弱词直接删，技能名本身即可 |
| 独立思考 / 团队协作能力强 | 用"项目职责"条目里的实际角色体现 |
